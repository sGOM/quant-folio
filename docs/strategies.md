## 0. 공통 신호 규약 (구현 사실)

모든 전략은 `signals.py`에서 다음 규약을 따릅니다. 이 규약을 먼저 이해해야 각 전략의 한계를 정확히 판단할 수 있습니다.

- **신호는 "크로스오버 이벤트"**: 조건이 `거짓→참`으로 바뀌는 봉에서만 신호가 발생합니다(`_cross_up`/`_cross_down`). 연속 봉에서 동일 신호가 중복 발생하지 않습니다. 즉 진입 후 청산 신호가 나오기 전까지는 추가 진입 신호가 없습니다.
- **입력 시계열**: 기본 전략(SMA/EMA/RSI/MACD/볼린저/돌파/모멘텀/z-score/이격도/donchian_squeeze/trix)은 종가(close) 단일 시계열을 입력으로 받습니다. **OHLC 전략(atr_trailing·volatility_breakout·keltner·stochastic·obv_trend)** 은 OHLCV DataFrame 을 받습니다(obv_trend 는 그중 close·volume 만 사용). `generate_signals(data, config)` 는 `data` 가 Series(종가)면 close-only 빌더로, DataFrame 이면 OHLC 빌더로 분기하며, close-only 빌더는 DataFrame 을 받아도 `close` 컬럼만 사용해 하위호환을 유지합니다(`requires_ohlc(config)` 로 입력 유형을 판별, 데이터 로더는 `get_close_series`/`get_ohlcv_frame` 로 공급).
- **체결 시점 가정**: 엔진(`engine.py`)은 vectorbt `Portfolio.from_signals`를 쓰며, 기본값 `fill_mode="next_close"`로 신호가 난 봉의 **익일(t+1) 종가** 에 체결합니다(당일 신호와 체결이 분리돼 미래참조가 없음). `same_close`(당일 종가 체결)는 민감도 분석용 opt-in 이며, 이 경우 신호와 체결이 같은 봉이라 미래참조 관점에서 별도 주의가 필요합니다(2장).
- **EMA는 `adjust=False`(재귀식)**: 실시간 엔진과 일관성을 위해 표준 재귀 EMA를 사용합니다. 올바른 선택입니다.
- **RSI는 Wilder 평활**(`ewm(alpha=1/period)`)을 사용합니다. 표준과 일치합니다.

## 1. 기존 전략 정리 (9종)

### 1.1 SMA Crossover (단순이동평균 교차) — `sma_crossover`

**개요**: 단기 단순이동평균(SMA)이 장기 SMA를 상향/하향 돌파할 때 매수/매도하는 고전적 추세추종 전략.

**신호 수식** (구현: `_ma_crossover_signals`, `_sma`)
- `SMA_n(t) = mean(close[t-n+1 .. t])` (`min_periods=n`, 미만 구간 NaN)
- 진입(매수): `SMA_fast(t) > SMA_slow(t)` AND `SMA_fast(t-1) <= SMA_slow(t-1)` (골든크로스)
- 청산(매도): `SMA_fast(t) < SMA_slow(t)` AND `SMA_fast(t-1) >= SMA_slow(t-1)` (데드크로스)
- 제약: `fast < slow` (위반 시 `ValueError`)

**금융학적 근거**: 가격에 추세(자기상관)가 존재한다는 가정. 이동평균은 노이즈를 평활해 추세 방향을 식별한다. 추세추종의 가장 기본형.

**파라미터**: `fast`(기본 5), `slow`(기본 20).

**적합 국면**: 명확한 방향성 추세장. 강한 상승/하락 추세에서 우수.

**주의·한계**:
- **횡보장 휩쏘(whipsaw)**: 박스권에서 잦은 교차로 거래비용만 누적, 연속 소액 손실.
- **지연(lag)**: 이동평균은 후행 지표라 추세 초반·종반을 놓침.
- SMA는 EMA보다 더 느리게 반응(과거 가중 동일).

**KRX 고려사항**: 골든크로스가 거의 매수신호로 알려져 군집 매매 → 슬리피지·체결지연 유발.

---

### 1.2 EMA Crossover (지수이동평균 교차) — `ema_crossover`

**개요**: SMA Crossover와 동일 구조이나 지수이동평균(EMA) 사용. 최근 가격에 더 큰 가중치.

**신호 수식** (구현: `_ema`, `adjust=False`)
- `EMA_n(t) = α·close(t) + (1-α)·EMA_n(t-1)`, `α = 2/(n+1)`
- 진입/청산: SMA Crossover와 동일한 골든/데드크로스 (대상이 EMA)
- 제약: `fast < slow`

**금융학적 근거**: SMA와 동일하나 반응성이 높아 추세 전환을 더 빨리 포착. 대신 노이즈 민감도 증가.

**파라미터**: `fast`(기본 12), `slow`(기본 26).

**적합 국면**: 추세장. SMA보다 빠른 진입을 원할 때.

**주의·한계**: 반응성↑ → 횡보장 휩쏘가 SMA보다 더 잦을 수 있음. 노이즈 거짓신호 증가.

**KRX 고려사항**: SMA와 동일. 12/26은 MACD의 기본값과 같아 MACD와 신호가 유사하게 움직일 수 있음(전략 분산 효과 제한).

---

### 1.3 RSI (상대강도지수, Wilder) — `rsi`

**개요**: RSI가 과매도(lower) 영역에서 상향 복귀하면 매수, 과매수(upper) 영역에서 하향 이탈하면 매도하는 **평균회귀(역추세)** 전략.

**신호 수식** (구현: `_rsi`, `_rsi_signals`)
- `delta = close.diff()`, `gain = max(delta,0)`, `loss = max(-delta,0)`
- `AvgGain = Wilder_EMA(gain, alpha=1/period)`, `AvgLoss = Wilder_EMA(loss, alpha=1/period)`
- `RS = AvgGain / AvgLoss`, `RSI = 100 - 100/(1+RS)`
- 경계 처리: `AvgLoss=0 → RSI=100`, `AvgGain=AvgLoss=0 → RSI=50`
- 진입(매수): `RSI(t) > lower` AND `RSI(t-1) <= lower` (과매도 상향 복귀)
- 청산(매도): `RSI(t) < upper` AND `RSI(t-1) >= upper` (과매수 하향 이탈)
- 제약: `lower < upper`

**금융학적 근거**: 단기 과매도/과매수 후 평균 회귀 경향. Wilder(1978) 표준 정의.

**파라미터**: `period`(기본 14), `lower`(기본 30), `upper`(기본 70).

**적합 국면**: **횡보·박스권**. 추세 없는 구간에서 우수.

**주의·한계**:
- **강한 추세장에서 치명적**: 상승추세에서 RSI가 70 위에 장기 체류 → 매도 후 추가 상승 놓침. 하락추세에서 30 아래 체류 → 떨어지는 칼 매수.
- 진입은 "30 상향 복귀", 청산은 "70 하향 이탈"로 설계되어 진입과 청산 사이에 비대칭이 있음. 진입했으나 RSI가 70까지 못 가면 청산 신호 부재 → 리스크 스탑 의존.

**KRX 고려사항**: 상·하한가 ±30% 도달 종목은 RSI가 극단값에 고정될 수 있음. 평균회귀 가정이 깨지는 급등락 종목 주의.

### 1.4 MACD — `macd`

**개요**: MACD 선이 시그널 선을 교차할 때 매매하는 추세추종/모멘텀 전략.

**신호 수식** (구현: `_macd`)
- `MACD = EMA_fast(close) - EMA_slow(close)` (EMA는 `adjust=False`)
- `Signal = EMA_signal(MACD)`
- 진입(매수): `MACD(t) > Signal(t)` AND `MACD(t-1) <= Signal(t-1)`
- 청산(매도): `MACD(t) < Signal(t)` AND `MACD(t-1) >= Signal(t-1)`
- 제약: `fast < slow`

**금융학적 근거**: 두 EMA의 모멘텀 차이로 추세 강도·전환을 포착. 시그널선 교차로 진입 타이밍 결정. Appel 표준.

**파라미터**: `fast`(12), `slow`(26), `signal`(9).

**적합 국면**: 추세장·모멘텀 구간.

**주의·한계**:
- 히스토그램(MACD−Signal)이나 0선 교차는 사용하지 않음(시그널 교차만).
- 횡보장 휩쏘. 후행성.
- 12/26 EMA를 쓰므로 EMA Crossover와 신호 상관 높음.

**KRX 고려사항**: 종가 기준이라 데일리 봉에서 신호 지연. 분봉 운용 시 파라미터 재검토 필요.

### 1.5 Bollinger Bands (볼린저밴드) — `bollinger`

**개요**: 종가가 하단밴드를 상향 복귀하면 매수, 상단밴드를 하향 이탈하면 매도하는 **평균회귀** 전략.

**신호 수식** (구현: `_bollinger_signals`)
- `Mid = SMA(close, period)`
- `σ = rolling_std(close, period, ddof=0)` (모표준편차 — 볼린저 관례. pandas 기본은 ddof=1(표본)이라 그대로 쓰면 밴드가 약 2.6% 넓어져 교차 타이밍이 어긋남)
- `Upper = Mid + num_std·σ`, `Lower = Mid - num_std·σ`
- 진입(매수): `close(t) > Lower(t)` AND `close(t-1) <= Lower(t-1)`
- 청산(매도): `close(t) < Upper(t)` AND `close(t-1) >= Upper(t-1)`
- 제약 없음(period, num_std 양수 가정)

**금융학적 근거**: 가격이 ±2σ 밴드 내에서 평균회귀한다는 가정. Bollinger 표준.

**파라미터**: `period`(20), `num_std`(2.0).

**주의·한계**:
- **밴드워크(band walking)**: 강추세에서 가격이 밴드를 타고 지속 이동 → 평균회귀 신호가 역방향. 추세장 손실.
- 진입(하단 복귀)과 청산(상단 이탈)이 비대칭. 진입 후 상단밴드까지 못 가면 청산 부재 → 스탑 의존.

**KRX 고려사항**: 변동성 확장 시 밴드가 급격히 벌어져 신호 빈도 변동. 저유동성 종목은 σ 추정 불안정.

### 1.6 Breakout / Donchian (돌파) — `breakout`

**개요**: 직전 N봉 최고가를 상향 돌파하면 매수, 최저가를 하향 돌파하면 매도하는 추세추종(돌파) 전략.

**신호 수식** (구현: `_breakout_signals`)
- `Upper = rolling_max(close, period).shift(1)` (당일 제외)
- `Lower = rolling_min(close, period).shift(1)` (당일 제외)
- 진입(매수): `close(t) > Upper(t)` AND `close(t-1) <= Upper(t)`
- 청산(매도): `close(t) < Lower(t)` AND `close(t-1) >= Lower(t)`

**금융학적 근거**: 신고가/신저가 돌파는 추세 개시 신호(터틀 트레이딩 계열). 채널 돌파 = 모멘텀.

**파라미터**: `period`(기본 20).

**적합 국면**: 추세 개시·확장 구간. 변동성 확대 국면.

**주의·한계**:
- **종가 기준 채널** — 표준 Donchian은 고가/저가(high/low)로 채널을 만듭니다. 현재 구현은 **종가의 rolling max/min**이라 장중 돌파를 놓치고, 진폭이 과소평가됩니다.
- **`shift(1)`로 미래참조를 올바르게 차단**한 점은 우수 — 채널 계산에 당일 종가 미포함.
- 거짓 돌파(false breakout) 빈발. 돌파 후 되돌림.

**KRX 고려사항**: 상한가 직행 종목은 종가만으로는 돌파 강도 식별 불가. 갭 상승 직후 체결은 슬리피지가 크다.

### 1.7 변동성 스퀴즈 돌파 — `donchian_squeeze`

**개요**: 일간 변화(1차 차분)의 산포 형태로 정의한 "스퀴즈" 상태가 해제되는 봉에서, 종가가 중심선(SMA) 위에 있으면 매수하는 변동성 확장 추종 전략. 청산은 중심선 하향 돌파. **이름과 달리 Donchian 채널(고가·저가 채널)은 사용하지 않습니다** — 레지스트리 키의 역사적 명칭이며, 계보상으로는 TTM 스퀴즈(John Carter)의 변형에 가깝습니다.

**신호 수식** (구현: `_donchian_squeeze_signals`, `_sma`, `_cross_down`)
- `r(t) = close(t) − close(t−1)`
- `σ_bb = rolling_std(r, period, ddof=0)` (모표준편차)
- `σ_kc = rolling_mean(|r|, period)` (평균절대값)
- `squeeze_on(t) = bb_mult·σ_bb(t) < kc_mult·σ_kc(t)` ⇔ `σ_bb/σ_kc < kc_mult/bb_mult`
- `mid = SMA(close, period)`
- 진입(매수): `squeeze_on(t−1) AND NOT squeeze_on(t)`(스퀴즈 해제) AND `close(t) > mid(t)`
- 청산(매도): `close(t)`가 `mid(t)`를 하향 돌파(`_cross_down`). 진입 봉은 제외(동일 봉 동시신호 금지)
- 제약: `period >= 3`, `bb_mult > 0`, `kc_mult > 0`(위반 시 `ValueError`)
- 최소 봉 수(`min_periods`): `period + 2`

**금융학적 근거**: 변동성 군집성(volatility clustering) — 압축 구간 뒤에 변동성 확장·추세 개시가 온다는 가설(볼린저 스퀴즈·TTM 스퀴즈 계열). 여기에 중심선 필터를 얹어 확장 방향이 위쪽일 때만 롱으로 진입한다.

**단, 구현된 판정식은 변동성 "수준"이 아니라 "분포 형태"를 측정한다(중요)**: `squeeze_on`은 `σ_bb/σ_kc < kc_mult/bb_mult`와 동치이고 이 비율은 **스케일 불변**이다(모든 `r`에 상수배를 해도 불변). 즉 가격 변동폭이 절반이 되어도 스퀴즈 상태는 그대로여서, **저변동 압축을 탐지하지 못한다**. 실제 측정 대상은 표준편차 대 평균절대편차 비율, 곧 일간 변화 분포의 꼬리 두께(첨도)다. 평균 0 정규분포에서 이 비율은 `√(π/2) ≈ 1.2533`이고, 점프·이상치가 섞일수록 커진다. 기본 임계 `kc_mult/bb_mult = 1.3`은 이 정규 기준값보다 약 3.7% 위다. 따라서 신호의 실질 해석은 "저변동 압축 해제"가 아니라 **"최근 n봉 변화 분포에 큰 점프가 섞여 산포비가 정규 수준을 넘어선 순간 + 종가가 중심선 위" = 점프·변동성 확장 추종**이다. 그 자체로 무의미하지는 않으나(변동성 확장 돌파), 표준 TTM 스퀴즈와는 다른 지표임을 전제로 해석해야 한다.

**파라미터**: `period`(기본 20), `bb_mult`(기본 1.0), `kc_mult`(기본 1.3). 실질 자유도는 `period`와 **비율 `kc_mult/bb_mult`** 둘뿐 — 두 배수는 개별로 의미가 없고 비율만 신호를 바꾼다.

**적합 국면**: 변동성 확장·추세 개시 구간. 중심선 필터 덕에 하락 추세에서는 진입이 억제된다.

**주의·한계**:
- **표준 TTM 스퀴즈와 불일치**: 표준은 가격 **레벨** 기준 볼린저밴드가 켈트너(ATR) 채널 안으로 완전히 들어간 상태를 스퀴즈로 본다(변동성 수준 비교). 현 구현은 양쪽 척도를 모두 일간 차분 기반으로 통일해 스케일 불일치(√n 배)를 제거했으나, 그 과정에서 **변동성 수준 정보 자체가 소거**됐다. 수준 기반 스퀴즈를 원한다면 `σ_bb`를 자기 과거 분포의 하위 분위(예 20% 이하)로 판정하는 방식이 대안이다.
- **코드 docstring 표현이 부정확**: `_donchian_squeeze_signals`의 docstring은 스퀴즈 ON을 "변동이 고르고 **작은** 상태"로 서술하나, 위 스케일 불변성 때문에 "작은"은 성립하지 않는다("고른(꼬리가 얇은)"만 맞음) — 코드 수정 여부는 별도로 판단할 사항이라 여기서는 문서화만 한다.
- **임계값 취약성 — 빈도가 임계에 비단조**: `kc_mult`가 너무 낮으면 스퀴즈가 거의 ON 되지 않아 해제 이벤트가 없고, 너무 높으면 상시 ON 상태에서 해제 조건을 넘지 못해 역시 신호가 없다. 신호 빈도는 산포비 분포의 최빈값 근처에서 최대가 되고 양쪽 극단에서 0으로 소멸한다 — `kc_mult`는 "많이/적게"의 손잡이가 아니라 **"켜짐/꺼짐" 스위치**에 가깝다. 판정 경계(1.3)가 정규 기준값(1.2533) 바로 옆이라 이 파라미터는 과최적화에 특히 취약하다.
- **진입·청산 비대칭**: 진입은 "스퀴즈 해제 이벤트", 청산은 "중심선 하향 돌파"로 조건의 종류가 다르다. 청산 후 재진입하려면 **새 스퀴즈 해제 이벤트**가 필요해, 중심선 위에서 추세가 재개돼도 재진입 신호가 없을 수 있다.
- **회전율·비용**: 산포비가 임계 부근에서 진동하면 해제 이벤트가 반복된다. 왕복 실효비용 ≈ 0.23%(2장) 기준으로 신호 수를 먼저 세고 비용 반영 후 성과로 판단할 것.

**KRX 고려사항**: 진입은 대개 **큰 변화(점프) 봉 직후**에 발생해 갭·수급 이벤트·상하한가(±30%) 근접 직후 매수가 되기 쉽다. 이 구간은 체결 충격이 평시보다 커 엔진 기본 `slippage_bps=5`가 낙관적일 수 있으니, 검증 시 상향 또는 `slippage_vol_scale` 활성화를 권고한다.

### 1.8 TRIX (삼중지수평활 모멘텀) — `trix`

**개요**: 종가를 EMA로 세 번 평활한 계열의 일간 변화율(%)을 모멘텀 지표로 삼고, 그 지표가 자기 시그널선(EMA)을 상향/하향 교차할 때 매매하는 추세추종·모멘텀 전략.

**신호 수식** (구현: `_trix_signals`, `_ema`)
- `ema1 = EMA_period(close)`, `ema2 = EMA_period(ema1)`, `ema3 = EMA_period(ema2)`(모두 `adjust=False` 재귀식)
- `TRIX(t) = (ema3(t) − ema3(t−1)) / ema3(t−1) × 100`(전일 대비 % 변화율)
- `Signal(t) = EMA_signal_period(TRIX)`
- 진입(매수): `_cross_up(TRIX, Signal)`, 청산(매도): `_cross_down(TRIX, Signal)`
- 제약: `period >= 1`, `signal_period >= 1`(위반 시 `ValueError`)
- 최소 봉 수(`min_periods`): `3·period + signal_period`(기본값 기준 3·15+9 = **54봉**)

**금융학적 근거**: Jack Hutson(1980년대 초, *Technical Analysis of Stocks & Commodities*)의 표준 정의와 일치한다 — 삼중 지수평활로 지정 주기보다 짧은 순환(노이즈)을 3단 감쇠시키고, 남은 저주파 성분의 변화율만 모멘텀으로 읽는다. 시그널선 교차로 타이밍을 잡는 용법도 표준(MACD 유사). 변화율(%) 기반이라 **가격 스케일에 무관**해 종목 간 값 비교·공통 임계 사용이 가능하다는 점이 MACD(원 단위 차이) 대비 장점이다.

**파라미터**: `period`(기본 15, 삼중 EMA 공통 기간), `signal_period`(기본 9).

**적합 국면**: 중기 추세장. 지정 주기보다 짧은 순환을 3단 감쇠하므로 단일 EMA 교차 대비 잔파동 내성이 구조적으로 높다(실제 우열은 표본 외 비교로 확인할 사항).

**주의·한계**:
- **지연이 큽니다**: EMA_n의 평균 지연 ≈ `(n−1)/2`봉, 삼중이면 ≈ `3(n−1)/2` = 21봉(기본 15), 시그널선 `(9−1)/2 ≈ 4`봉이 더해져 실효 지연 약 **25거래일(≈5주)**. 추세 초·종반을 크게 놓치고 급반전에서 청산이 늦어 손절 레이어 의존도가 높다.
- **웜업 54봉**: 기본값에서 첫 신호까지 최소 54거래일 데이터가 필요하다. 짧은 백테스트 구간·신규 상장 종목에서는 유효 표본이 크게 줄어든다.
- **0선 교차·다이버전스 미구현**: 표준 TRIX의 다른 용법인 0선 교차(추세 방향 전환)는 사용하지 않는다(시그널선 교차만).
- **MACD·EMA 교차와의 상관**: 세 전략 모두 "EMA 파생 모멘텀의 시그널선 교차"라는 동일 구조다(1.2·1.4의 상관 경고와 같은 맥락). 다중 전략 운용 전 신호 중복률 측정을 권고한다.

**KRX 고려사항**: 변화율 기반이라 **수정주가(액면분할·무상증자 반영) 사용이 전제**다. 미조정 계열이면 분할일에 `ema3`가 계단형으로 꺾여 대형 허위 신호가 발생한다. 종가 단일 시계열만 필요해 데이터 요구는 가장 가볍다.

### 1.9 OBV 추세 크로스오버 — `obv_trend`

**개요**: 부호부 누적 거래량(OBV)이 자기 이동평균(SMA)을 상향/하향 교차할 때 매매하는 거래량 모멘텀 전략. `signals.py`에서 **거래량(volume)을 사용하는 유일한 전략**이다.

**신호 수식** (구현: `_obv_trend_signals`, `_sma`)
- `sign(t) = sign(close(t) − close(t−1))`(상승 +1 / 하락 −1 / 보합 0, 첫 봉은 0)
- `OBV(t) = Σ_{k≤t} sign(k)·volume(k)`(누적합)
- `OBV_MA = SMA(OBV, period)`
- 진입(매수): `_cross_up(OBV, OBV_MA)`, 청산(매도): `_cross_down(OBV, OBV_MA)`
- 제약: `period >= 2`. 입력은 **OHLCV DataFrame**(`close`·`volume` 필수)
- 최소 봉 수(`min_periods`): `period + 1`

**금융학적 근거**: Granville(1963)의 OBV — 가격 변화의 방향에 그날 거래량 전체를 가산해 "거래량이 가격에 선행한다"는 가설로 매집/분산을 추적한다. 대수적으로 전개하면 `OBV(t) − SMA_n(OBV)(t)`는 **최근 부호부 거래량에 선형감소 가중을 준 합**과 같아, 이 교차는 "최근 n봉에서 거래량 가중 상승일이 하락일을 압도하기 시작한 시점"을 포착한다. 가격 이동평균 교차가 *가격 변화 크기*는 보되 *거래량*을 무시하는 것과 정확히 반대로, OBV는 *거래량 크기*는 보되 *가격 변화 크기*는 무시한다(+0.1%일과 +10%일이 동일 취급) — 정보 축이 상보적이라는 점이 분산 근거다. `cumsum`의 시작점(0)은 임의값이지만 OBV·OBV_MA 양쪽에 동일하게 반영되므로 교차 신호에는 영향이 없다.

**파라미터**: `period`(기본 20).

**적합 국면**: 거래량이 동반되는 추세 개시·확장 구간. 유동성이 두텁고 거래량 계열이 안정적인 대형주.

**주의·한계**:
- **가격 조건이 없다 — "확증 필터"가 아니다**: 진입에 가격 돌파·추세 조건이 전혀 없어, 3.9절 원안("가격 신고가 AND OBV 신고가")과 달리 거짓 돌파 필터로 기능하지 않는다. 하락 국면이라도 하락일 거래량이 얕고 상승일 거래량이 두꺼우면 매수 신호가 날 수 있다.
- **보합일 정보 소실**: `sign=0`이면 그날 거래량이 통째로 버려진다. 보합이 잦은 저유동 종목·가격제한폭 부근에서 왜곡된다.
- **거래량 이상치에 계단 반응**: 블록딜·지수 편출입 리밸런싱·유상증자·거래재개일의 대량 거래 한 번이 OBV에 큰 계단을 만들고 이후 `period`봉 동안 OBV_MA를 끌고 다닌다(신호 지연·왜곡).
- **SMA 교차와의 상관**: OBV 증분의 부호가 `sign(Δclose)`라 가격 이동평균 교차와 방향이 자주 일치한다. 분산 효과는 거래량 가중분에서만 나오므로, 조합 운용 전 `sma_crossover`와의 신호 중복률 측정을 권고한다.

**KRX 고려사항**: 거래량 계열이 **수정주가와 정합적으로 조정됐는지 확인이 필요**하다(액면분할·병합 시 거래량 스케일 점프 → OBV 계단). 저유동·소형주는 거래량 노이즈가 커 OBV 추세가 불안정하고 단일 대량 거래로 신호가 좌우된다.

| 중간 | 손절이 종가 기준(장중 저가 미반영) | ⚠️ 미해소 — vectorbt `sl_stop`/`tp_stop`/`sl_trail` 은 close-only. 손절 손실이 낙관적 |

| 중간 | 표본 외 검증 부재 | 🟡 DSR(P2-1)·워크포워드 스크립트(`scripts/wf_id23.py`). 자동 분할·UI 는 미구현 |
| 낮음 | 지표가 rf=0 Sharpe 뿐 | ✅ `risk_free_rate` 기준 Sharpe·Sortino, 리밸런싱은 CAGR·alpha/beta/IR(P0-2)·팩터 IC(P1-1) |

올바르게 구현된 부분: EMA `adjust=False`·Wilder RSI(표준 일치), breakout `shift(1)`(채널 미래참조 차단), 크로스오버 이벤트화(중복 신호 방지), `min_periods`(시드 부족 차단).

**KRX 호가단위**(2023.1.25 개편, 코스피·코스닥 공통) — 저가주는 호가 비율이 커 비용 오차가 거래세에 필적(4,000원에서 5원 = 0.125%):

| ~2,000원 | 1원 |

## 3. 추가 전략 제안

선정 기준: 한국 시장 적합성, 데이터 가용성, 기존 전략과의 분산, 구현 난이도.

| 순위 | 전략 | 분류 | 필요 데이터 | 상태 |
|---|---|---|---|---|
| 1 | ATR 트레일링(샹들리에) | 추세추종+청산 | OHLC | ✅ `atr_trailing` |
| 2 | 변동성 돌파(래리 윌리엄스) | 추세/모멘텀 | OHLC | ✅ `volatility_breakout` |
| 3 | 절대모멘텀(타임시리즈) | 모멘텀 | close | ✅ `momentum` |

| 5 | 평균회귀 z-score | 평균회귀 | close | ✅ `zscore` |

구현된 전략의 수식은 `signals.py` 가 단일 출처다. 제안 원안과 구현이 갈리는 지점만 적는다.

### 3.1 ATR 트레일링 — `atr_trailing`

진입=Donchian 돌파 `close > rolling_max(High, period).shift(1)`, 청산=`close` 가 샹들리에
`rolling_max(High, period) − k·ATR` 하향 돌파(ATR 은 Wilder). `period`/`atr_period` 22, `k` 3.0.
변동성 비례 손절폭으로 고정 % 손절(`stop_loss_pct`)의 한계를 보완.

### 3.2 변동성 돌파 — `volatility_breakout`

`Target(t) = Open(t) + k·(High(t−1) − Low(t−1))`, 진입=`High(t) ≥ Target`, `k` 0.5. 원안의 당일
종가 청산은 동일 봉 동시신호 금지 규약 때문에 **다음 봉 청산**(`entries.shift(1) & ~entries`).
일봉 엔진이라 장중 돌파를 봉 종료 후 평가 — **원안(장중 체결 데이트레이딩)과 체결 가정이 다르고
슬리피지에 민감**하다.

### 3.3 절대모멘텀 — `momentum`

`close/close.shift(lookback) − 1` 의 0선 교차(`lookback` 120). 원안의 월말 리밸런싱 대신 크로스오버
이벤트로 신호화(Moskowitz·Antonacci).

### 3.4 듀얼모멘텀 (미구현)

자산별 `Mom_i` 중 1위를 고르되 그 `Mom ≤ 0` 이면 현금/안전자산(Antonacci). 코스피200 ETF·채권 ETF
조합에 적합. 다종목 리밸런싱 엔진으로 구현 가능.

### 3.5~3.7 z-score · 켈트너 · 스토캐스틱

- `zscore`: `z = (close − SMA)/std`, `−entry` 상향 복귀 진입·0 상향 돌파 청산(`period` 20, `entry` 2.0). 볼린저의 연속화 — 추세장 취약도 같다.
- `keltner`: `Mid = EMA(close)`, `Upper = Mid + mult·ATR`, `Upper` 상향 돌파 진입·`Mid` 하향 돌파 청산(20/10/2.0). 표준편차 대신 ATR 이라 추세추종형.
- `stochastic`: `%K`(고저 동일 구간은 50 으로 0/0 방지)·`%D = SMA(%K)`, 과매도에서 `%K↑%D` 진입·과매수에서 하향 청산(14/3/20/80).

### 3.8 변동성 타게팅

`weight = min(1, σ_target/σ_realized)`. 리밸런싱은 `risk_layer`(`max_leverage` 1.0 캡 — 디레버리징 전용)로
구현됐다. **단일종목 러너의 "가용현금 전액" 사이징(2장)에는 아직 없다** — 여기 적용하는 것이 남은 개선.

### 3.9 거래량 동반 돌파 — `obv_trend` 는 원안과 다르다

원안은 "가격 신고가 **AND** OBV 신고가"라는 **거짓 돌파 확증 필터**였으나, 구현된 `obv_trend` 는 가격
조건 없는 OBV 자기 이동평균 교차다(1.9). **breakout 보강 목적은 미구현**, VWAP 계열도 미구현.

### 3.10 이격도 — `disparity`

`100·close/SMA`, `lower` 상향 복귀 진입·`upper` 하향 이탈 청산(20/95/105, RSI식 대칭).

## 4. 공통 권고 (아직 유효한 것)

비용·체결·지표 권고는 2장대로 반영됐다. 검증 절차는 `.claude/rules/validation-workflow.md`.

- **워크포워드·민감도**: 단일 기간 최적 파라미터를 믿지 말고 인접값 성과 안정성을 함께 본다.
- **편향 점검**: 생존편향(상장폐지 포함)·미래참조·데이터스누핑(전략 선택 자체의 과최적화).
- **시장 제약**: 정규장 09:00~15:30, 결제 T+2(현금 회전), 거래정지·관리종목 제외.
- **일일 손실 한도**: `check_daily_loss_limit` 은 신규 진입만 차단한다. 기존 포지션 청산 정책은 미정.
- **상관 리스크**: EMA 교차·MACD·TRIX 는 같은 "EMA 파생 모멘텀의 시그널 교차" 구조, OBV 는 SMA 교차와
  방향이 자주 겹친다. 다중 전략 운용 전 신호 중복률을 측정한다.
- **지표 해석**: 승률은 손익비(평균이익/평균손실)와 함께 본다. 거래 수가 적으면 통계적 신뢰도가 낮다.

구현은 quant-engine, 코드 리뷰는 review 계열 에이전트.
